# Third-party material

## Fonts (vendored)

| Family | Use | License | Files |
|---|---|---|---|
| Rajdhani | headings and HUD numbers | SIL Open Font License 1.1 | `assets/fonts/rajdhani-*.woff2`, license text `assets/fonts/OFL-Rajdhani.txt` |
| Inter | body text | SIL Open Font License 1.1 | `assets/fonts/inter-*.woff2`, license text `assets/fonts/OFL-Inter.txt` |

Where the files came from and which subset was kept is recorded in `assets/fonts/README.md`.

## Nothing else

There is no other third-party code or asset in this repository: no npm runtime dependencies (the dev server, tests and experiments use Node built-ins only), no images or icon packs (every visual is drawn procedurally in canvas, SVG and CSS), and no audio files (every sound is generated procedurally with the Web Audio API). Charts and figures are hand-written SVG.
