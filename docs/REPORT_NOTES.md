# Siege Mind: report notes

The project report is generated: [PROJECT_REPORT.md](PROJECT_REPORT.md) (run `npm run report-doc`). Its hand-written sections are in `docs/report/`; its results section embeds the headline, the confirmatory results, the limits and the non-claims of [RESULTS.md](RESULTS.md) word for word. Edit the section files, never the generated report.

Where each topic of a class report lives:

| Topic | Where |
|---|---|
| Game design, modes and explainability | `docs/report/02-game.md`, [DIRECTOR.md](DIRECTOR.md) |
| Architecture and engineering practice | `docs/report/03-architecture.md`, `docs/report/04-engineering.md` |
| Dynamic difficulty background and the research question | `docs/report/05-method.md`, [EXPERIMENT.md](EXPERIMENT.md) |
| Results and figures | [RESULTS.md](RESULTS.md), `docs/results/figures-final/` |
| Limitations and future work | `docs/report/07-limits-and-future.md` |
